# stock_hunter 审核与改进报告

- **版本**：基于 v8.0 审核
- **日期**：2026-07-29
- **审核范围**：`main.py` + `modules/` 全部 8 个模块、`config.json`、`history/daily_summary.json`
- **系统定位**：通过每日扫描感知**板块热度变化**，最终服务于**选股**

---

## 一、现状数据流

```
watchlist_jiuyan.json
    → 腾讯K线拉取150日历史行情（ifzq.gtimg.cn，10线程并发）
    → D1-D9 个股打分（满分 37 分，打板/龙头战法信号体系）
    → 按韭研分类求「平均分」生成板块总排名
    → TOP5 精选（去重 + 板块多样性约束）
    → Excel 报告 + 飞书推送
    → 飞书推送时顺手写 history/daily_summary.json（5日对比箭头）
```

**一句话结论：系统目前是「每日静态快照」，尚不是「热度变化感知」，更没有形成选股反馈闭环。**

---

## 二、核心差距分析（对照"感知板块热度变化 → 选股"目标）

### 2.1 板块排名指标区分度太差 🔴

板块排名完全依赖 D1-D9 的平均分。D1-D9 是打板/龙头战法信号（涨停、连板、一字板、150日新高），分布极度稀疏。

从 `history/daily_summary.json` 实测数据看：板块平均分仅 **1.6 ~ 3.9 分**，板块间差距在零点几分，属于**噪声级差异**，无法分辨"谁热谁冷"。

**真正的板块热度需要「广度 + 量能」指标，目前完全缺失：**

| 缺失指标 | 说明 | 数据可得性 |
|---|---|---|
| ❌ 上涨家数占比 / 涨幅中位数 | 板块广度 | 现有数据可算 |
| ❌ 涨幅 > 3% 家数占比 | 板块广度 | 现有数据可算 |
| ❌ 板块成交额放大倍数（今日总额 / 5日均额） | **热度最核心信号** | K线数据已有 `amount` 字段，只是没算 |
| ❌ 成交额加权排名 | 旧版韭研系统曾有，v8.0 反而丢失 | 现有数据可算 |

现有广度指标仅有「涨停数」和「前排率」，但前排率基于 D1/D2（新高突破）——**板块从冰点启动初期，前排率纹丝不动**，对"升温"不敏感。

### 2.2 "变化"感知是附属品，且不可靠 🔴

- 5日对比逻辑藏在 `push_feishu.py` 中：**飞书推送成功才写历史**，推送失败/未配置则历史断档
- 对比结果只出现在飞书文本的 ↑↓ 箭头里，**不进 Excel 报告**
- 没有"加速 / 升温 / 退潮 / 冰点"的趋势判定逻辑
- 热度感知是系统的一等目标，却挂在最边缘的模块上

### 2.3 TOP5 是"事后确认"不是"选股" 🔴

- 得分高 = 已经涨停/连板/创新高 → 按此买入即追高
- D5/D6（潜在突破）是仅有的左侧信号，权重仅 2+1 分，被淹没
- 无高位风险降权：连板 ≥ 3 恰恰是风险最大的标的，D7+D8 反而加 11 分

### 2.4 没有反馈闭环，无法迭代调参 🔴

系统从不记录"昨天推荐了谁、今天表现如何"。**没有胜率/收益跟踪，所谓持续优化只能靠拍脑袋。** 这是从"报告生成器"进化为"选股系统"最关键的一块拼图。

## 四、优化路线图

### P0 — 让系统真正感知热度（改动小、收益最大）

**1. 新增板块热度分（0-100）**

```
热度分 = 加权(
    涨停数,
    上涨家数占比,
    涨幅>3%家数占比,
    成交额放大倍数(今日总额 / 5日均额),   ← K线数据已够算
    前排率
)
```

**2. 历史模块独立为 `modules/heat_tracker.py`**

- 每天**无条件**写历史（不再依赖飞书推送）
- 计算 3 / 5 / 10 日热度斜率
- 输出趋势标签：`🔥加速 / 📈升温 / ➡️平稳 / 📉退潮 / 🧊冰点`
- 写入 Excel 新 Sheet + 飞书推送

**3. 修复 `base_dir` 指向 `E:\stock_hunter`**

> P0 三项为同一工作量的改动，全部基于现有数据源，无需新增外部依赖。完成后系统从"每日快照"变为"热度温度计"。

### P1 — 建立选股闭环

**4. 推荐跟踪**

- 每日保存 TOP5 到 `history/picks.json`
- 次日自动回算"昨日推荐今日表现"（胜率、平均涨幅）
- 推送与报告中携带命中率——**有了命中率才能谈调参**

**5. 榜单分两层**

- 确认型：已涨停/连板，追强势股
- 左侧型：D5/D6 突破 + 量能放大，低吸候选
- 连板 ≥ 3 标注高风险

### P2 — 数据补全

**6. 换手率 / 量比**：补一次腾讯快照请求（`_fetch_spot_tencent` 现成但未被调用），合并进历史数据

**7. ST 股涨停判定修正**（5% 阈值）

## 五、验收标准（建议）

| 指标 | 现状 | 目标 |
|---|---|---|
| 板块排名区分度 | 平均分差距 0.x 分（噪声级） | 热度分拉开梯度，TOP3 与末位差距 ≥ 20 分 |
| 热度趋势标签 | 无 | 每日输出加速/升温/退潮/冰点判定 |
| 推荐命中率跟踪 | 无 | 每日回算昨日 TOP5 胜率并推送 |
| 历史数据可靠性 | 依赖飞书推送成功 | 独立模块无条件落盘 |
