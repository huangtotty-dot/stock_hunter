## 二、核心问题：量能放大维度是"死"的（两个叠加 bug）

### 🔴 Bug 1：前 5 日对比被"今天必须已在历史中"门控

`modules/heat_tracker.py` 中量能放大的历史回查逻辑：

```python
past_entries = history.get(date_str, [])   # 查的是"今天"
past_amounts = []
if past_entries:                           # ← 致命：今天不在历史中就不查历史
    sorted_dates = sorted(history.keys())
    idx = sorted_dates.index(date_str) ...
    for i in range(max(0, idx - 5), idx):  # 这段永远执行不到
        ...
avg_amount_5d = _avg(past_amounts) if past_amounts else amount_total
amount_amplify = amount_total / max(avg_amount_5d, 1)   # 恒 = 1.0
```

- 正常每天首次运行时，`date_str` 不在 history 中（保存发生在函数末尾）→ `if past_entries:` 为 False → **前 5 日成交额回查整段被跳过**
- `amount_amplify` 恒为 1.0，**量能放大 20 分永远是 0**
- 只有同一天重复跑第二次才触发 → **同一天第一次跑和第二次跑热度分不一致，评分不可复现**

**修法**：去掉 `if past_entries` 门控：

```python
sorted_dates = sorted(history.keys())
idx = sorted_dates.index(date_str) if date_str in sorted_dates else len(sorted_dates)
for i in range(max(0, idx - 5), idx):
    ...
```

### 🔴 Bug 2：字段名与单位双重不匹配

- 回查找的 key 是 `s.get("成交额总额", 0)`
- `_save_sector_history` 写入的 key 是 `"成交额总额(亿)"`
- **永远匹配不到**，即使 Bug 1 修复也查不到数据
- 单位也不一致：存的是亿元，`amount_total` 是元

**修法**：统一字段名为 `成交额总额`，统一单位为元。

## 三、趋势判定逻辑的三个缺陷（重点审核项）

> 用户问题：判定当天状态（上升/平稳/下降），理论上应与前 5 日状态比较。审核确认：实现框架确实做了历史对比，但有三处会给出错误结论。

### 🟡 缺陷 1：冷启动期结论不可信

`_get_past_scores` 过滤条件为 `s.get("热度分", 0) > 0`：

- fix1 之前的旧历史（20250620/21/25 等）没有"热度分"字段 → 全部排除 → **上线后前 5 个交易日所有板块 slope=0，恒为 ➡️平稳**
- 真实的 0 分（冰点板块）也被排除 → 抬高历史均值、系统性压低 slope

**修法**：改用 `"热度分" in s` 判断字段存在性，而非值非零。

### 🟡 缺陷 2："对比均值"识别不了方向

当前公式：`slope = 今日 - mean(前3/5日)`，再混入 `slope_long = 今日 - 前5日最早一日`，各占 50%。

反例：

| 走势形态 | 数据 | 当前判定 | 实际状态 |
|---|---|---|---|
| V 形 | 30→10→10→10→10，今日 25 | 升温（高于均值14） | 离 5 天前的 30 还差得远 |
| 高位连跌初期 | 30→30→30→29→28，今日 28 | 平稳（slope≈-0.5） | 退潮初期 |
| 尖峰后回落 | 5 天前脉冲 50，其后 20 横盘 | slope_long 强负 → 退潮 | 可能是正常横盘 |

**均值对比对序列形状不敏感**；`slope_long`（对比最早一日）会让 5 天前的尖峰压垮最近 3 天的真实反弹。

**修法建议**：对前 5 日得分做**线性回归斜率**（识别过去方向）+ **今日 vs 昨日**（识别当日边际变化），两者结合判标签。

### 🟡 缺陷 3：阈值 ±5/±15 是未校准的绝对分

- 量能 20 分已死，热度分实际满分只有 80
- 上涨广度（0-20）每天随大盘普涨普跌大幅摆动，±5 很可能在噪声范围内

**修法建议**：攒一周数据后按各板块 slope 的历史分布校准（如用过去 slope 的 ±1σ 作阈值）。
