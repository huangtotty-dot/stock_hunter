## 二、重点审核项：报告展示效果不突出重点

> 用户反馈：观看报告时显示效果不够突出重点。审核确认属实，问题集中在 Sheet 1（概念总排名）——恰恰是承载热度感知的核心页面。

### 🔴 2.1 热度分/趋势列零视觉强调

`_build_summary_sheet` 通过通用 `_write_dataframe` 写入：表头深蓝、数据行全白。新增的**热度分**、**趋势**两列与"细分数量""前排率%"等辅助列视觉上完全平等：

- 热度分无颜色梯度（openpyxl 支持 `ColorScaleRule`，全项目未使用任何条件格式）
- 趋势只有 emoji 文本（🔥/📉 渲染依赖 Excel 字体），无底色区分——加速应红色系、冰点应蓝色/灰色系
- TOP3 高热板块行无加粗/高亮

**后果**：打开 Sheet 1 第一眼无法定位"今天哪个板块最热、在变热还是变冷"，需要逐行扫数字——热度感知系统的核心价值被展示层吞掉了。

### 🔴 2.2 "热度TOP5" 横条是死代码（永不渲染）

`reporter.py:224`：

```python
if data_start_row == 2 and not df_summary.empty and "热度分" in df_summary.columns:
    heat_top5 = df_summary.head(5)
    top5_txt = "热度TOP5: ..."   # ← 永远执行不到
```

只要 overview 文本存在（几乎恒成立，平均分总能算出），`data_start_row` 在第 221 行就被置为 3，此分支永远进不去。**本应是 Sheet 1 最醒目的"热度TOP5速览条"，实际从未出现过。**

### 🟡 2.3 关键信息挤成一行纯文本

第 2 行 overview 把"加权/等权平均分 + 平均分最高最低 + 热度最高最低"全部 `｜` 拼接进一个合并单元格，无层级、无重点色，属于"信息墙"。

### 🟡 2.4 TOP5 Sheet 含死列，行动信息缺失

- `D3突破形态` 列：scorer v10 已删除 D3 维度，`stock.get("D3突破形态", 0)` 恒为 0，**死列占据 TOP5 黄金位置**（reporter.py:272,286）
- TOP5 是全报告最"可执行"的一页，却不展示该股所属板块的**热度分/趋势/成交额放大倍数**——用户无法判断"这个强势股所在的板块是否在升温"

### 🟡 2.5 板块明细 Sheet 的涨停统计口径错误

`reporter.py:312` 子概念排名用 `涨跌幅 >= 9.9` 统计涨停数：

- 与 market_data 的判定（9.5 阈值、ST 5%、科创/创业 19.5%）**口径不一致**
- 对 30/68 开头股票，+15% 被误计为涨停；9.5%~9.9% 的主板涨停被漏计
- 同一报告内 Sheet 1 的"涨停数"（用 `涨停` 字段）与板块 Sheet 的"涨停数"会对不上

## 四、逻辑残留问题（非展示）

### 🟢 4.1 涨停密度分子分母口径不一致

去重后 `total` 是不重复股票数，但 `limit_up_count` 取自 summary 行的"涨停数"（由 data_loader 在未去重的 cat_df 上统计）。同一股票在同一分类有多个概念对时会被重复计入分子 → 涨停密度轻微高估。建议 heat_tracker 内自行用 `df_dedup["涨停"].sum()` 计算。

### 🟢 4.2 趋势公式残留边界：高位滞涨误判

回归斜率只看前 5 日（不含今日）。若板块过去 5 天强势上行（斜率+10）、今日横盘（边际 0），combined = 6 → 仍判"🔥加速"，但今日已失速。建议把今日纳入回归序列，或对"斜率高但边际≈0"降一档。

### 🟢 4.3 冷启动分支阈值不一致

冷启动分支用 ±5/±2，主分支用 ±3/±1——同样的 delta 在历史长度不同时判不同标签。建议统一。
